Notas de arquitectura NoSQL

Sin claves foráneas

Firestore es una base NoSQL orientada a documentos. No existen JOINs ni FK. Las referencias entre colecciones son lógicas y las mantiene la capa JS.

Dos subsistemas de reserva

reservations es el flujo web manual (BookingManager). iotReservations es el flujo de sensores ESP32 (ParkingManager). Ambos escriben en reservationHistory.

Tiempo real (onSnapshot)

BookingManager, ParkingManager, StatsManager y CameraApp usan onSnapshot() para reflejar cambios en vivo sin recargar la página.

IoT bridge

El ESP32 escribe en parking/estado (sensores). El web lee iotReservations y control/servos para controlar las barreras de entrada/salida.
